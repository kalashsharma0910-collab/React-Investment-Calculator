# React Investment Calculator

A simple React app that helps users estimate how an investment grows over time based on the initial amount, annual contributions, expected return rate, and investment duration.

## Features

- Input fields for:
  - Initial investment
  - Annual investment
  - Expected return percentage
  - Duration in years
- Real-time calculation of yearly investment growth
- Currency-formatted results table
- Clean and beginner-friendly UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Project Preview

This project is a practical front-end exercise for learning state management, reusable components, and financial calculations in React.

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the app locally

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Upload to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/your-username/investment-calculator.git
git push -u origin main
```
